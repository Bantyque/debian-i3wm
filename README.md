## ⚙️ Stack

* **OS:** Debian 13
* **WM:** i3wm 
* **Terminal:** Alacritty 
* **Compositor:** Picom 
* **Bar:** Polybar
* **Launcher:** Rofi
* **Shell:** Zsh + Powerlevel10k
* **Editor:** Neovim 
* **Notifications:** Dunst
* **Audio:** PipeWire + WirePlumber + EasyEffects
* **Colors:** Pywal + Wpgtk

## 🚀 Installation

Recommended on a minimal Debian install.

```bash
git clone [https://github.com/Bantyque/debian-i3wm.git](https://github.com/Bantyque/debian-i3wm.git)
cd debian-i3wm
chmod +x *.sh
./install.sh
